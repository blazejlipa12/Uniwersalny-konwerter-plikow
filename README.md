# Uniwersalny-konwerter-plikow

Celem projektu jest zaprojektowanie aplikacji desktopowej, która pozwala wybrać plik wejściowy, pokazuje wyłącznie
dostępne dla niego formaty docelowe, wykonuje konwersję i zapisuje wynik we wskazanym
katalogu. Projekt ma utrwalić podstawy Pythona, pracę z systemem plików, integrację bibliotek i
narzędzi zewnętrznych oraz obsługę błędów w aplikacji z GUI.

Zakres aplikacji:
aplikacja powinna wspierać co najmniej 6 kierunków konwersji z
trzech grup: dane strukturalne, tekst/dokument oraz dokument/PDF
